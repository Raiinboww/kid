💑 부부 실시간 동기화

현재 이 기기(로컬)에만 저장되고 있습니다. 아래에 Firebase 주소를 연결하면 남편과 와이프가 변경하는 내용이 실시간으로 함께 반영됩니다.
와이프에게 연결 정보 보내기
📖 3분 무료 실시간 연동 설정 방법 (Firebase)
  1. Firebase 콘솔에서 구글 로그인 후 프로젝트 추가 (무료 Spark 요금제).
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 클릭.
  3. 위치는 싱가포르(asia-southeast1) 선택 후 테스트 모드로 시작.
  4. 생성된 상단 주소(https://...firebasedatabase.app)를 복사해 위 칸에 붙여넣기!
  5. 방 코드에 두 사람만 아는 코드를 적고 실시간 연동 시작을 누르면 끝!
  6. 와이프 폰에는 연결 코드 복사해서 카톡으로 보내고 붙여넣기만 하면 바로 동기화됩니다.

서버 설정 없이 현재 체크리스트 전체를 코드로 복사해 카톡으로 주고받거나 파일로 백업할 수 있습니다.
